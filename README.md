# GreenDISC certification for ICCS RSE Team

This repository is being used to track progression for the ICCS RSE team towards [GreenDiSC Certification](https://www.software.ac.uk/GreenDiSC)

There is an [associated project board](https://github.com/orgs/Cambridge-ICCS/projects/59) to track issues and progression.
