# Evidence for GreenDiSC Bronze

This directory collects evidence for each Bronze criterion as we work towards
certification, and is maintained for recertification (every 2 years)
and future Silver/Gold applications.

Evidence may live here directly (documents, screenshots, exports) or be linked
from here (e.g. Google docs/sheets, team webpages). Anything an auditor
cannot open should be exported or screenshotted into this repo.

## Structure

Evidence is grouped by GreenDiSC category, with one subdirectory per criterion:

* `general/`: G1 to G4
* `offices/`: O1 to O3
* `data-storage/`: DS1 and DS2
* `compute/`: HPC1 to HPC3

Each criterion directory has a README stating the criteria, what evidence it
contains, and how it is maintained.
