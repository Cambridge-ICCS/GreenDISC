# Data Storage

The directory contains evidences for the Data Storage Category for each of the underlying criteria (DS1-DS2).

## DS1-B: Catalog the major data resources used

ICCS works on other researchers' projects in a consultancy capacity. As a result we rarely hold long-term datasets of our own, and mostly work with data that belongs to, and is stored and managed by, the partner researchers. When we do use data, we aim to share good data practice with the groups we work with (e.g. avoiding duplicate copies and cleaning up at the end of a project).

1. Filled inventory

    The `Data Resource Inventory` tab lists the major datasets and storage used for ICCS work in the last 12 months, both managed by the team and external.

    - [Data Resource Inventory sheet](https://docs.google.com/spreadsheets/d/15jcCD2Ig1MkHKncvauN3nEL2SgUuFa67DVHn6lpF7fg/edit?gid=595366698#gid=595366698)

    - **Data held by ICCS:** ICCS does not own data in long-term, and any copies that we may make are transferred back to the researchers at the end of the project with a clean of personal/team storage scheduled at the end of a project.

## DS2-B: Start a data cleaning process

1. Policy and where it is located

    The "Data Cleaning" section of the ICCS Sustainability Policy (team handbook) sets out the process:

    - **When:** at the end of each project which is usually 3 months or 6 months with possibility of extension to 1 year.
    - **Who:** Project Leads, after discussing with the project RSEs. Individuals clean up their own personal usage.
    - **Where:** office laptops, shared spaces on CSD3, RDS, etc. Each person deletes only their own project-specific directories.
    - **What is kept:** data needed beyond the project needs a reason (e.g. possible extension, reproducibility, shared with other projects). Data the PI needs afterwards is transferred to them, or ownership is transferred.

    _Screenshot: [Data Cleaning Policy.png](DS2-data-cleaning/Data%20Cleaning%20Policy.png)_ (the handbook is a private repository)


2. Status of the first clean

    As ICCS does not own any significant data sources (see DS1), a clean has not yet been carried out. In line with the handbook policy, the first clean is scheduled for the end of the current projects, and will be carried out by each Project Lead with their project RSEs.
