# O1: Computing hardware inventory

Evidence for GreenDiSC Bronze criterion **O1**: an inventory of the computing
hardware used by the ICCS RSE team.

**Update frequency:** Yearly

## Contents

* The current hardware inventory (export of the shared sheet, or a link to it)
* A note of when it was last reviewed and by whom

## Inventory

Based on the
[reference inventory template](https://docs.google.com/spreadsheets/d/1GEUPeHO6CnJhCOhJHdSKYH6c0cKhPyXy3UUZzWpv7WI).

Each entry should record:

* Device type (laptop, desktop, monitor, server, etc.)
* Make and model
* Owner / user
* Purchase date and expected replacement date
* Status (in use, spare, awaiting disposal)
